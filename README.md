REPOSITORIO
Dentro de este repositorio se realizara el desarrollo del proyecto final, donde se guardara y organizara cada avance a lo largo del semestre, en donde se enfocara en aplicar los conceptos y habilidades dentro de la materia de esta manera logrando realizar un producto mínimo viable como entrega final, asimismo el desarrollo de este proyecto es parte de las actividades academicas de la asignatura de Taller de Programación, por lo cual este repositorio sera el lugar en el cual se realizara el control de versiones y su desarrollo 

OBJETIVOS DE PROYECTO

- Desarrollar y realizar la entrega de un software funcional o producto mínimo viable

- Mejorar habilidades de solucion de problemas y habilidades en cuanto al desarrollo de software

ENFOQUE DE DESARROLLO
El proyecto se realizara de forma iterativa e incrementar a lo largo del semestre por lo que se seguira una metodologia Scrum el cual el proceso de desarrollo del software sera:

Product Backlog and Goal setting: En esta etapa se definira el alcance del producto junto con sus requerimientos e sprints individuales para cada etapa de desarrollo

Sprint Planning: En esta etapa se organizara cada uno de los temas a desarrollar durante cada uno de los sprints, estableciendo trazabilidad y una linea de tiempo clara

Sprint Execution: En esta etapa se empezara con la implementación de las funcionalidades dentro del proyecto

Countinuous Integration: En esta etapa se adaptará cada una de las partes del código para asegurar su sincronización y de que cada componente sea estable y que no genere problemas

Quality Assurance: En esta etapa se realizara la validacion y verificacion de la funcionalidad del codigo a traves de revisiones, debuggings y ciclos de testeo para su correcto funcionamiento

Analysis: En esta ultima etapa se realizara la documentacion de las especificaciontes tecnicas, logs durante la fase de desarrollo, y su respectivo analisis critico para realizar la evaluacion de eficiencia y del producto a lo largo del desarrallo

MVP Delivery: Por ultimo se entregara el producto mínimo viable funcional para una evaluación al final del semestre


El proyecto sigue en fase de desarrollo por lo que lo los requerimientos e funcionalidades se agregaran durante todo el semestre concluyendo con la entrega de un producto mínimo viable MVP
